# SM-S9280 / S9280ZCS6DZF2 offline payload profile

This profile targets the mainland-China Galaxy S24 Ultra (`SM-S9280`, device
`e3q`, product `e3qzcx`) on firmware `S9280ZCS6DZF2` and kernel
`6.1.145-android14-11-3254743-abS9280ZCS6DZF2`.

## Imported target material

The target symbols and 13-row P0 fingerprint table were imported from the
matching adb temporary-root kit. The profile was normalized to this
repository's `target.h` and `p0_fingerprint.h` ABI before building the app
payload. The original input hashes are recorded in the transaction
verification file.

The common E3Q structure layout and physical-map constants are inherited from
the repository's audited `e3q-S928USQS6DZF2` profile. Firmware-specific symbol
values, the `SKB_DATA_DELTA`, and the P0 rows come from the DZF2 target material.

## Build result

The app payload was built twice from the repository sources with Android NDK r30. Both unpadded builds were byte-identical (88128 bytes, SHA-256 `3664baef5e6f85793d40895471fa2e20ab3623a094d514c1783da284890e0798`) and were padded to the repository release size of 104128 bytes. Its path is:

`artifacts/e3q-S9280ZCS6DZF2/cve-2026-43499-app.so`

The matching KernelSU userspace artifact is:

`kernelsu/ksud-e3q-S9280ZCS6DZF2-kdp`

## Validation status

The normalized source compiles, the result is an AArch64 shared object, and
artifact sizes and hashes are verified. Hardware validation is not recorded in the supplied material. Per the deployment
request, this profile is listed in `support/targets-v3.json`;
`support/targets-v2.json` remains unchanged.
